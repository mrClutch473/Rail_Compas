## Туту

- Next.js. Выдача: `https://www.tutu.ru/poezda/<From>/<To>/?date=ДД.ММ.ГГГГ&travelers=1`, города транслитом с заглавной (`Volgograd`, `Moskva`, `Sankt-Peterburg`).
- Предложения через WebSocket `offers-api.tutu.ru`, адрес сокета в `__NEXT_DATA__`.
- На странице: номер, отправление/прибытие, вокзалы, в пути, классы, места, цены «от», иногда зачёркнутая цена и кешбэк. Есть реклама и баннеры.
- Ещё: `vid-api.tutu.ru/api/calendar_prices` (календарь минимальных цен), `www.tutu.ru/poezda/vkz/api/timetable` (табло вокзала).
- Капчи не было. Форма поиска капризная, адрес выдачи открывается напрямую.
- План: сокет → `__NEXT_DATA__` → DOM. Ссылка для пользователя = адрес выдачи.

Проверить: формат сообщений сокета и признак конца; «поездов нет»; есть ли код класса обслуживания; местное или московское время; `calendar_prices`; подсказки городов → слаг; сбор в цене; `robots.txt`; поведение с серверного IP.

## Ozon Travel

- Nuxt. Маршрут: `https://www.ozon.ru/travel/railway/volgograd-177578000/moskva-140158000/` (слаг + внутренний ID).
- Первая загрузка может дать «Antibot Challenge Page» (403), JS-проверка проходит сама за несколько секунд; при частых запросах может ужесточиться.
- На странице маршрута цены «от» по классам **без привязки к дате**, выбор даты ведёт в форму поиска.

Главный вопрос — цена на дату. Пути: (1) пройти форму в `probe --headed`, взять итоговый адрес выдачи; (2) найти внутренний запрос выдачи в HAR, вызывать из контекста страницы; (3) запасной — календарь цен маршрута (минимум по дате без поездов).
Проверить также: сохраняется ли пройденная проверка в профиле; сколько загрузок подряд проходит; ID городов через подсказки; время; сбор в цене; `robots.txt`; поведение с серверного IP и через прокси.

Если цену на дату получить нельзя → Ozon только в календаре цен, третий источник становится важнее.

Официальный продавец → эталон тарифа, наценка посредников к нему. Раньше `pass.rzd.ru` отдавал расписание с ценами двухшаговым запросом (идентификатор → результат) [не проверено, данные до 2024]. Сейчас `ticket.rzd.ru`. Проверить: выдача на дату, формат, защита, совпадение с ценой посредников без сбора.

## УФС, Sravni, Яндекс

- УФС (`ufs-online.ru`): выдача, формат, защита.
- Sravni (`sravni.ru/booking-rw`): свой поиск или виджет другого продавца (тогда бесполезен).
- Яндекс: одна контрольная проверка капчи; есть — закрыт окончательно.

## Правила

Капчи не решаем никак. Не входим в аккаунты. Без стелс-плагинов и подделки отпечатков. Прокси автора используем для стабильной работы с серверного IP, но если площадка показывает капчу — это стоп, а не повод перебирать прокси. Паузы и дневные бюджеты соблюдаем, тяжёлые ресурсы не грузим.
