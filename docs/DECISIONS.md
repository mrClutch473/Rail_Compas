| D-18 | 21.11 | Django 5.2 LTS, Python 3.13, PostgreSQL 16, uv, ruff, Tailwind v4 standalone, htmx, Chart.js | LTS, установлено у автора, без Node.js и SPA |
| D-19 | 21.11 | Один Docker-образ на web и worker на базе образа Playwright; сервер 2 vCPU / 4 ГБ | Одинаковое окружение локально и на сервере; Chromium требует памяти |
| D-21 | 21.11 | Локально `probe` запускает установленный Chrome/Edge, если Chromium из Playwright не стартует; профили браузера раздельные по каналу | Chromium 159 не запускается на Windows 26300 (ошибка side-by-side). В Docker на Linux не касается |
| D-22 | 21.11 | **Принято:** на этапе STAGE сравниваем только цены без скидок (у Туту — `priceOld`, если есть скидка). Пометки о скидках банков — позже. Запросы с одним постоянным `sessionId` (меняется раз в сутки); на сайте пометка, что Туту показывает персональные цены и цена на площадке может отличаться | Сравнение одинаковых условий; персональные цены не контролируем, честнее зафиксировать одну сессию и предупредить |
| D-23 | 21.11 | **Предложено:** Туту собираем прямым запросом к `offers-api` (нет robots.txt, не трогает запрещённые страницы), браузер только как запасной путь; `/ajax/` не используем | Легче для сервера, быстрее для кнопки, уважает robots.txt сайта |
| D-24 | 21.11 | **Принято:** второй источник — OneTwoTrip вместо Ozon. Его `gdsCost` (цена без комиссии посредника) показываем как ориентир «тариф перевозчика» | Ozon, УФС, Яндекс недоступны для автоматического сбора; OneTwoTrip отдаёт JSON без браузера с сервера РФ |
| D-25 | 21.11 | **Принято:** третий источник — Aviakassa (JSON API без браузера). Итого: Туту, OneTwoTrip, Aviakassa + базовая цена без комиссии из OneTwoTrip (`gdsCost`) как ориентир | Все три работают с сервера РФ, все на кодах Express, ни одной не нужен браузер |
| D-26 | 21.11 | **Предложено:** склейка рейсов — основной ключ `маршрут + номер + дата`; если номер не совпал, запасной — `маршрут + точное время отправления + номера отличаются на 1 (чётный/нечётный)`, `*` в номере отбрасываем, оба номера храним | Поезда с двойной нумерацией: `357*С` у Aviakassa = `358С` у Туту |
| D-27 | 21.11 | **Принято:** базовая (официальная) цена = ⌈`gdsCost` − `tariffService`⌉ из ответа OneTwoTrip; сайт РЖД и сертификат НУЦ пока не нужны (вернёмся, если понадобится Т-Путешествия или прямой РЖД) | Ручная сверка 9 цен с сайтом РЖД: совпадение 9/9 |
| D-28 | 21.11 | **Принято:** рабочий Docker-образ на `python:3.13-slim` без Playwright и Chromium; Playwright только в группе `recon` для разведки. Заменяет часть D-19 | Все три площадки отдают JSON без браузера; экономия памяти на сервере с 2 ГБ |
| D-29 | 21.11 | **Принято:** плацкарт сравниваем без постельного белья — минимальный тариф площадки, как «от» у РЖД. У OneTwoTrip вычитаем `tariffService`; у Aviakassa проверить в фазе 9 | Одинаковая основа для всех площадок и эталона |
| D-30 | 22.11 | **Принято:** цвета площадок — категориальные слоты 1–3 проверенной палитры (синий, оранжевый, бирюзовый; свои оттенки для тёмной темы) по порядку `Source.priority`, тариф РЖД — нейтральный серый пунктир; проверено валидатором: CVD ΔE 9,2, обычное зрение 27 | Прежние фирменные цвета (фиолетовый/голубой/оранжевый) не проходили проверку различимости и контраста |
