# Решения

Коротко: что решили и почему. Пересмотр — новая строка со ссылкой «заменяет D-N».

| № | Дата | Решение | Почему |
|---|---|---|---|
| D-1 | 21.11 | Название «ЖД Компас», репозиторий `Rail_Compas` | Автор |
| D-2 | 21.11 | Код и комментарии на английском, интерфейс на русском | Автор |
| D-3 | 21.11 | Первый этап — Волгоград и его направления; города и маршруты только в БД, в коде привязки нет | Расширение без правок кода |
| D-4 | 21.11 | Без регистрации и избранного на первом этапе | Не главное для диплома, перспективы |
| D-5 | 21.11 | **Всё на одном сервере:** сайт, воркер парсинга, БД. Связи с ПК автора нет. Заменяет идею брифа о сборе на домашнем ПК | Независимость от устройства; честная демонстрация на защите |
| D-6 | 21.11 | **Синхронизация по кнопке** на маршрут+дату, метка «обновлено N мин назад», автозапуск при отсутствии данных | Комиссия может сверить цены вживую; свежие данные по запросу |
| D-7 | 21.11 | Фоновое расписание только для популярных маршрутов (`is_scheduled`) | У большинства посетителей данные уже есть; история цен копится |
| D-8 | 21.11 | Очередь заданий в PostgreSQL (`SKIP LOCKED`) + воркер `run_worker`; без Celery и Redis | Нагрузка маленькая; проще и прозрачнее для записки |
| D-9 | 21.11 | Защита от перегрузки: cooldown 5 мин, одно задание на маршрут+дату, лимит с IP, предел очереди, бюджет площадки | Кнопка не должна стать способом завалить площадку и получить бан |
| D-10 | 21.11 | Прокси автора поддерживаются на уровне площадки | Серверные IP блокируют строже |
| D-11 | 14.11, 21.11 | Капчи не решаем; без стелс-плагинов и подделки отпечатков; JS-проверку, которую браузер проходит сам, ждём | Этика, правила брифа |
| D-12 | 21.11 | Поиск по справочнику городов; маршрут создаётся при первом поиске; справочник первого этапа — Волгоград + направления | Компромисс: работает как настоящий поиск, но без произвольных городов |
| D-13 | 21.11 | Пакет `scraper` без Django; адаптер = `fetch` (сеть) + `parse` (чистая функция) | Тесты на фикстурах, replay, починка без запросов к площадке |
| D-14 | 21.11 | Порядок стратегий: сеть → состояние страницы → DOM | Структура данных меняется реже вёрстки |
| D-15 | 21.11 | Текущая выдача = снимки последней успешной задачи каждой площадки; снимки только добавляются | Исчезновение класса = «нет мест»; история без отдельных таблиц |
| D-16 | 21.11 | Пять классов вагонов, люкс отдельно от СВ | Не искажать сравнение СВ |
| D-17 | 21.11 | Кешбэк и баллы не вычитаются из цены, показываются пометкой | Честное сравнение витринных цен |
| D-18 | 21.11 | Django 5.2 LTS, Python 3.13, PostgreSQL 16, uv, ruff, Tailwind v4 standalone, htmx, Chart.js | LTS, установлено у автора, без Node.js и SPA |
| D-19 | 21.11 | Один Docker-образ на web и worker на базе образа Playwright; сервер 2 vCPU / 4 ГБ | Одинаковое окружение локально и на сервере; Chromium требует памяти |
| D-20 | 21.11 | Документация компактная (ARCHITECTURE, SOURCES, DECISIONS), роадмап подробный | Документацию использует Claude, важен контекст |
